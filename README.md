# FlowUs Recording Rules

本仓库包含用于在 FlowUs 中整理记录的 Agent Skills：

- `record-flowus-paper`：录入论文并生成结构化学习笔记。
- `write-flowus-experiment-report`：根据用户填写的实验信息和提供的材料，简要完善指定的实验报告。

列出或安装仓库中的 skill：

```bash
npx skills add NanHaibei/flowus-recording-rules --list
npx skills add NanHaibei/flowus-recording-rules --skill record-flowus-paper
npx skills add NanHaibei/flowus-recording-rules --skill write-flowus-experiment-report
```
